# ⚖️ The Defense Docket
A turn-based legal defense procedural simulation engine built for Google Gemini, featuring a client-side companion dashboard.

## ⚡ How to Play
1. **Launch the Engine:** Copy the prompt from [`SYSTEM_PROMPT.md`](./SYSTEM_PROMPT.md) and paste it into a fresh Gemini chat (or create a custom Gemini Gem).
2. **Open the Companion Site:** Access your active case tools, objection cheat sheet, and turn tracker via GitHub Pages.
3. **Link Your Case:** Complete Phase 0 in Gemini, type `/generate`, and paste the JSON into the dashboard's Auto-Extract tool.

## 📁 Files
* `index.html` - The single-file companion dashboard (runs offline in-browser via localStorage).
* `SYSTEM_PROMPT.md` - Complete game engine instructions, legal fail states, and checkpoint protocols.
